## Background

G3 freezes the collateralization math before any circuit work: the collateral
ratio (§5.D1) and the emergency-tier thresholds (§5.D8, DL-24 corrected formula).
The acceptance bar is a Rust + TypeScript implementation agreeing byte-for-byte on
**≥ 200 fixtures spanning every dimension** (incl. edge cases: `supply = 0`,
extreme supply, price extremes), plus the M4a circuit re-deriving the same outputs
(a 3-way Rust = TS = circuit match) so the circuit cannot silently diverge.

## The formulas (frozen)

```
collateral_ratio_ppm(reserve_sats, supply_atoms, price_e8):
    supply_atoms == 0            → undefined (None)
    num = reserve_sats · price_e8 · 1_000_000        (widened to u128)
    den = supply_atoms · 10^14
    cr_ppm = floor(num / den)                          (asserted ≤ u64::MAX)

recompute_tier(cr_ppm):
    None              → Healthy      (no outstanding SatUSD to back)
    cr_ppm ≥ 1_500_000 → Healthy     (≥ 150%)
    cr_ppm ≥ 1_300_000 → PauseMint   (≥ 130%)
    cr_ppm ≥ 1_100_000 → Auction     (≥ 110%)
    else               → Settlement  (< 110%)
```

The `10^14` denominator term reconciles the unit dimensions (sats, cent-atoms,
price·10^8); the documented §5.D8 "tiny supply" row prints `5×10^14` but the
formula yields `5×10^10` for `reserve=1e8, price=5e12, supply=100` — a PRD print
typo, not a formula error (ADR-003). All multiplications widen to `u128` before
dividing (§ arithmetic-safety rule). Mint capacity is re-checked at finalize on
the **post-mint** supply (DL-27, ADR-004).

## Evidence — ≥ 200 fixtures, 3-way verified

The `tier` op in the shared vector file
(`integration/vectors/vectors.json`, generated by `satusd-vectors`) now carries
**327 fixtures** (was 7):

- The 7 documented §5.D8 scenarios + threshold boundaries (150/130/110/100%).
- Dimension edges (§18.3 ranges): `supply = 0` (undefined → Healthy), `reserve = 0`
  (cr 0 → Settlement), all-max (`reserve = 21M BTC`, `supply = 10^14`,
  `price = 10^14`), max-reserve/min-price, 1-sat reserve / max supply.
- A full `reserve × supply × price` sweep (12 × 6 × 3), plus a targeted CR sweep
  that solves `reserve = cr · supply · 10^8 / price` to land in each band — incl.
  the narrow PauseMint/Auction ranges and the exact boundaries.

Tier-band coverage: **Healthy 118, PauseMint 34, Auction 35, Settlement 140**,
plus the undefined-CR edge.

| Check | Command | Result |
|---|---|---|
| Rust = TypeScript byte-match | `make verify` | 4460 assertions, 0 fail |
| Rust = TS = **circuit** (cr_ppm + tier) | `circuits/check.sh` | 326 tier vectors match (the `supply=0` edge is CR-undefined, so the circuit, which assumes `supply>0`, skips it) |

The M4a circuit (`m4a_cr_tier.circom`) re-derives `cr_ppm` via in-circuit
Euclidean division (`cr_q`, `cr_r` witnesses with u64 range + `0 ≤ r < den`) and
the tier via `GreaterEqThan` comparators — so the gate also confirms the circuit's
collateralization gadget matches the frozen formula on all 326 defined fixtures.

## Conclusion

G3 **passes**: the CR/tier formulas are frozen (ADR-003), the finalize-time
re-check semantics are pinned (ADR-004), and Rust, TypeScript, and the M4a circuit
agree on 326 fixtures spanning every band and dimension extreme — well past the
≥ 200 bar. M4 circuit work may proceed.
