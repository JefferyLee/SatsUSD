比特币的规则。

一种BTC 超额抵押、美元计价的 Taproot Asset，活在比特币 L1 上。持有不需要许可，赎回不需要中介，验证只需要一个比特币节点。抵押品是外生的 BTC——和挂着自家代币循环抵押的 UST 是两种范畴的东西。

赎回怎么跑

价格一到，合约自己结算。
没有人批准任何事。

结算前，价格区间被切成桶，每个桶预签一笔加密的结算交易——密钥是 oracle 对那个价格的签名本身。Oracle 按秒见证价格；见证一到，只有命中的桶能解密，其余永远打不开。广播可以是任何人。

开放市场

兑换通道不是基础设施，
是一个任何人都能进的市场。

任何人都可以运营一条「rail」：自带 oracle 方案、费率、速度，符合一套公开标准即可，无需许可。Rail 能从储备金提取的额度不靠身份背书，只靠一个公式：capacity = ½ × (累计留存费 + 质押)。后果：跑路在任何时刻都是亏本生意。

终局

每一笔结算，
本身就是一次价格见证。

当兑换量足够大，这些链上结算点就汇聚成一个无签名者的价格源：任何观察者算出同一个数。外部 oracle 从「信任根」降级为「合理性锚」——价格信号由市场自己生产。这是自指（self-referencing），但抵押品始终是外生的 BTC：自指的是信息，不是抵押。

演示：成交量加权中位数 + 5% 修剪带。一头试图操纵价格的鲸鱼（红点，偏离 40%）被修剪带直接弹掉——标记纹丝不动。算法与实现一致（spec 03 §5.2）。
